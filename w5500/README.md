# W5500

> STM32 F103C8T6 + W5500
>
> [点击此处](https://github.com/Wiznet/ioLibrary_Driver/) 获取 W5500 官方驱动程序

## 连接关系

| STM32 开发板 | W5500 模块 |
| :---------: | :-------: |
|     5V      |    5V     |
|     GND     |    GND    |
|     PA4     |    SCS    |
|     PA6     |   MISO    |
|     PA5     |    SCK    |
|     PA7     |   MOSI    |
|     PB4     |    RST    |
|     PB5     |    INT    |
